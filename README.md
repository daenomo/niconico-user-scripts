# niconico-user-scripts

ニコニコ動画向けの Tampermonkey 用ユーザースクリプト一覧です。

## インストール方法

1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) などのユーザースクリプト管理拡張機能をインストールします。
2. インストールするスクリプトのリンクを開き、ソースコードをすべてコピーします。
3. Tampermonkey のダッシュボードで「新規スクリプトを作成」を選択します。
4. エディターにコピーしたコードを貼り付け、保存します（通常は `Ctrl + S`）。
5. 対象のニコニコ動画視聴ページを再読み込みします。対象ページは各スクリプトのリンク先にある `@match` を確認してください。

## スクリプト一覧

| [フルスクリーン固定タイトル表示](./Niconico-Fullscreen-Title-Display.user.js) | ニコニコ動画を全画面表示した際、操作中に動画タイトルを表示します。 |
| [シアターモード切り替え](./NicoVideo-Theater-Mode-Toggle.user.js) | `T` キーで動画をブラウザ幅いっぱいに拡大・縮小します。 |
